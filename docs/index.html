Three Pillars

机制不重复，推荐叠加

各自作用于 Token 管道的不同段，Combined 效果远大于单点优化。

📥

Headroom

在 Agent 与模型之间压缩 bulky 输入——日志、JSON、大文件。可逆检索，决策信息不丢。

input-optimization
💬

Caveman

缩短解释性 prose。代码、命令、报错信息字节级保留——只砍废话，不砍精度。

output-optimization
✂️

Ponytail

生成最少正确代码。七级梯从删注释到删抽象，安全红线始终在线。

code-minimization
Decision Tree

30 秒定位瓶颈

账单高？先诊断，再选策略——避免「全装一遍」的无效优化。

diagnosis.txt 
账单高？
├─ 工具读回日志/大文件多 → Headroom + input-optimization
├─ 回复解释很长         → Caveman + output-optimization
├─ 生成代码臃肿         → Ponytail + code-minimization
├─ 多轮历史长           → 新会话 + claude-mem / MemPalace
└─ MCP 工具描述过长     → caveman-shrink
